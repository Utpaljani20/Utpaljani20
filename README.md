**SkinBuzz** is a Machine Learning-based web application developed for Mumbai University (BscIT) that helps detect various skin diseases from uploaded images using Convolutional Neural Networks (CNN).

---

## 🚀 Features
* **Image Upload:** Users can upload images of skin conditions.
* **Deep Learning Prediction:** Uses a trained CNN model to analyze images.
* **User Authentication:** Secure Login and Signup system.
* **Responsive UI:** Clean and modern interface built with HTML/CSS.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** Flask (Python)
* **Machine Learning:** TensorFlow, Keras, OpenCV
* **Database:** SQLite / MySQL
